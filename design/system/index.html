Design system — direction C “Control room”

One token file design/tokens.css · components design/components.css → copied verbatim into web/ui/ when the app was built. Each section below draws the light and dark sets side by side.
01 · Mono is the main voiceNumbers, times, ids, labels, buttons and logs use IBM Plex Mono — columns line up and it reads like a control panel. Loop names and prose use IBM Plex Sans.
02 · The list is always thereThe 520px left pane is the loop list on every screen; the right pane changes with the route. No context is lost when viewing details.
03 · The log is the centreThe log always has a dark background in both modes, like a terminal window embedded in the page.
04 · One accent colourAmber = primary action + “Running”. Green / red / purple are only for run results. No decoration.
05 · Square, flat, information-dense0–4px radius, no shadows except dialogs, 1px dividers. Status always has a glyph alongside colour.
